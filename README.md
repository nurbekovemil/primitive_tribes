# 🔥 Первобытные племена

Онлайн 2D-стратегия: вы — вождь первобытного племени и сами отдаёте все приказы.

## Запуск (локально)

Нужны Node.js 20+ и pnpm (`corepack enable pnpm`).

```bash
pnpm install
pnpm dev
```

- Игра: http://localhost:5173
- Сервер мира: ws://localhost:2567 (порт меняется переменной `GAME_PORT`)

Второй игрок в той же сети открывает `http://<IP-вашего-компьютера>:5173`.

## Команды

| Команда          | Что делает                               |
| ---------------- | ---------------------------------------- |
| `pnpm dev`       | сервер и клиент с автоперезапуском       |
| `pnpm test`      | тесты (правила, симуляция мира, пути)    |
| `pnpm typecheck` | проверка типов во всех пакетах           |
| `pnpm lint`      | ESLint                                   |
| `pnpm format`    | Prettier                                 |

## Стек

TypeScript · pnpm workspaces · Vite · Phaser 3 (мир) · React 19 (интерфейс) · Colyseus 0.18 (онлайн, синхронизация состояния) · A* по сетке · Vitest · ESLint + Prettier.

## Структура

```
apps/
  server/            Colyseus-сервер, вся логика мира
    src/rooms/       WorldRoom — одна общая комната-мир
    src/state/       схема синхронизируемого состояния
    src/game/        World, люди, звери, племена, приказы, ИИ ботов, поиск пути
    test/            симуляция мира без сети
  client/            Vite + Phaser + React
    src/game/        отрисовка, камера, выделение, приказы мышью
    src/ui/          панели: ресурсы, выделение, мини-карта, журнал, помощь
packages/
  shared/            общие правила, константы, типы команд и состояния
```

Графика — PNG-картинки в стиле гладкой рисованной 2D (двойное разрешение) в `apps/client/public/assets`,
описаны в `sprites.json`. Все картинки с анимацией: http://localhost:5173/?art — чтобы заменить картинку,
положите PNG с тем же именем и размером кадра, логику трогать не нужно.

Сервер — единственный источник правды: клиент только отправляет приказы (`cmd`) и рисует состояние.
Правила, которые нужны обоим (что делает правый клик, можно ли строить, можно ли создать семью), лежат в `packages/shared`.

## Как играть

1. Выделите людей (клик или рамка) и отдайте приказ правой кнопкой: куст — собирать ягоды (женщины), дерево — рубить, зверь — охота (воины), туша — разделать.
2. Выделите взрослых, нажмите **B** и поставьте хижину рядом с костром.
3. Выделите семью и кликните правой кнопкой по готовой хижине — семья заселится.
4. Выберите хижину → **Родить ребёнка** (20 🍖). Ребёнок вырастает за минуту.
5. Выросшим создайте семью (выделить мужчину и женщину → **Создать семью**) или позовите невесту/охотника у костра.

Без приказов люди стоят на месте. Сами они только защищаются: воины отвечают на нападение, женщины и дети убегают к костру.
Хищники боятся огня. Племя ест раз в 15 секунд — следите за едой.
